## 🆓 Freemium Limitations

### 🎯 **Recommendation Restrictions**
- **1 recommendation per day** (configurable by admin)
- After daily limit: "*You've reached your daily recommendation limit. Upgrade to Premium for unlimited access.*"
- Recommendations reset at **00:00 UTC** daily
- No carryover of unused recommendations

### 📊 **Chart & Analysis Limitations**
- **Basic charts only** (limited timeframes)
- **Standard indicators** without advanced customization
- **Single timeframe** analysis (no multi-timeframe confluence)
- Limited **volume analysis** features
- No access to **institutional order flow** data

### 🔔 **Alert System Restrictions**
- **Limited alert slots** (typically 3-5 alerts)
- **Basic notification types** only
- No **advanced conditional alerts**
- **Delayed notifications** (not real-time priority)
- Limited **alert history** retention

### 💰 **Trade Manager Limitations**
- 🚫 **No access** to trade manager system
- 🚫 **No mathematical position sizing**
- 🚫 **No session-based tracking**
- 🚫 **No smart money management**
- 🚫 **No trade recording and analytics**

## 💡 Frequently Asked Questions

### **Q: Can freemium users access all signal types?**
**A:** Yes, freemium users receive the same high-quality signals as premium users. The limitation is on **recommendation frequency** (1 per day), not signal quality.

### **Q: What happens when I hit my daily recommendation limit?**
**A:** The system will display: "*You've reached your daily recommendation limit (1/1). Upgrade to Premium for unlimited access or wait until tomorrow (resets at 00:00 UTC).*"

### **Q: Do unused recommendations carry over?**
**A:** No, freemium recommendations reset daily and don't accumulate.

### **Q: Can I upgrade mid-session?**
**A:** Yes, premium benefits activate immediately upon upgrade.

### **Q: Can freemium users access the trade manager?**
**A:** No, the trade manager is a **premium-exclusive feature**. It requires advanced mathematical calculations and persistent session tracking that are only available to premium subscribers.

### **Q: Are there any hidden limitations for freemium users?**
**A:** All limitations are clearly disclosed. Freemium users receive full signal access with daily recommendation limits and reduced advanced features, but no access to the trade manager system.
